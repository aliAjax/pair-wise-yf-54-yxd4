# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。

## 展柜读数与条件判定（连续读数防抖）
- 限值：温度 15–25℃、湿度 40–65%、照度 ≤200 lux（见 `src/services/conditions.ts`），任一越限即记为一次越界读数。
- **连续 3 次越界**才把展品条件置为「异常」；单次抖动只在抖动账记一笔、结论保持「正常」，连成趋势后抖动账自动撤回。
- 异常后**连续 2 次合格**进入「待复核」，经**保管员复核**才恢复「正常」；恢复期内再越界则计数清零回到异常。
- 读数按采集时刻入库：同一时刻重复上报只留一条（后到覆盖），乱序到达自动归位；结论由完整序列实时重算，不缓存「已通过」。
- 保管员复核带被复核序列签名：补传/覆盖改动到已复核序列时复核立即作废并重算（审计痕迹保留并标红）。
- 上报读数携带终端基线版本号（乐观锁）：两个终端并发提交同一展柜时，后到的一方收到 `VersionConflictError`，须「读入最新版本」后重新提交。开两个浏览器标签页即可复现（`storage` 事件自动同步对方写入）。
- 纯领域逻辑在 `src/services/conditions.ts`，无框架依赖，可直接单测。
